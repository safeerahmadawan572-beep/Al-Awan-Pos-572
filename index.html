🎛️ Customize app

🌐 Online store page (public)

Creates a separate customer-only page from your current products: photos, prices and WhatsApp ordering. It does not include costs, stock counts, customers, khata, sales or expenses. Upload only that file online; keep this POS file private on your device. Create it again whenever prices or products change.

🔄 Live updates (rate / stock khud update ho)

Ek dafa setup karein, phir POS mein rate ya stock badalte hi online store khud update ho jata hai, page dobara upload nahi karna parta. Sirf naam, rate, category aur in-stock products public hote hain. Aap ka baqi data (sales, customers, khata, cost) private rehta hai.

  1. Cloud sync connect hona chahiye (neeche Backup / Settings mein).
  2. Neeche ka SQL copy karein. Supabase mein SQL Editor → New query mein paste karke Run dabayein (ek hi dafa).
  3. Neeche Live updates ON par tick lagayein.
  4. Phir Create online-store.html dabayein aur wo file ek dafa online upload karein.

☁️ Cloud sync (Supabase)

Every change is saved to your private Supabase database automatically, so you can recover everything if the phone is lost or reset. Setup steps are in the chat. Your data is protected by login and row-level security.

🧹 Start fresh (clear test data)

Use once, before entering real data. A backup file downloads first and you must type DELETE to confirm. If cloud sync is on, the cleared data replaces the cloud copy too, so keep that backup file safe.

🔒 PIN lock

Locks the screen after you stop using the app, and opens with a short PIN (4–6 digits). It is a convenience lock for the shop counter, not strong security.

Backup — Export & Import

Export a backup regularly. This app stores data in this browser on this device; it does not sync with other phones or computers.

Export saves a JSON backup file (or opens Android Share, so you can send it to Google Drive or WhatsApp). Import opens your file picker: choose the JSON backup from your device or Google Drive. Importing replaces the current data.

Privacy: the backup file contains your customers' khata and all sales. Keep it private and never upload it online.
